## Promise and workflow

A generic A2A client should be able to opt a registry agent into A2A, discover its Agent Card, send a JSON-RPC `SendMessage`, retry with the same `messageId` without duplicate delivery, and inspect the resulting task with `GetTask` and `ListTasks`.

The scratch server used SQLite registry/session stores, `CR_A2A_ENABLED=true`, `CR_GUARD_ENABLED=false`, and `CR_REQUIRE_AGENT_SIG=false` on port 18891. The server reported `registry_backend=sqlite`, `registry_durable=true`, `a2a_enabled=true`, and build commit `ca27c855`.
