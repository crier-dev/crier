# Dogfood real-use run — 2026-09-18

Promise tested: "a user can stand up a self-hosted agent message bus in one Go
binary and exchange messages over relay pub/sub, direct mesh RPC, durable
inboxes, and an MCP bridge."

Server: `CRIER_PORT=8769 CR_GUARD_ENABLED=false ./bin/crier -port 8769`
(in-memory backend, defaults otherwise). Built from f8b7247.

## What a real consumer actually does — and what happened

### 1. Relay pub/sub (websocket-client + urllib)
- Subscribe: `ws://host:8769/relay/subscribe/<topic-or-wildcard>` — no handshake
  payload needed; subscription is implicit in the URL.
- Publish: `POST /relay/publish` REQUIRES `X-Agent-ID` on default config
  (rate limiting on). Without it: 401 "X-Agent-ID header required..." — the
  integration-guide publish example omits the header (filed DOGFOOD-RELAY-4).
- Empty-topic publish: 202 and silently dropped; topic appears in
  GET /relay/topics only while ≥1 subscriber is connected. Documented; held up.
- **Frame shape surprise:** the subscriber receives the BARE event payload
  (`{"from":...,"body":...}`), NOT `{topic, event}`. A wildcard subscriber
  cannot tell which topic matched. Filed DOGFOOD-RELAY-1.

### 2. Mesh RPC (two websocket-client peers)
- Connect `ws://host:8769/mesh/connect/<agent_id>`, send one REGISTER frame
  (fire-and-forget — no ack, as documented), then REQUEST/RESPONSE.
- REQUEST relays verbatim; wrong/missing fields get a server ERROR frame.
- REQUEST to an offline/unknown peer → ERROR code CONTROLLER_OFFLINE with
  `request_id` = the failed REQUEST's message_id (useful, but the correlation
  contract for ERROR is undocumented — filed DOGFOOD-MESH-3).
- RESPONSE `body` per docs is a JSON-encoded STRING (json.RawMessage) and the
  wire matches, but the doc's own example shows an object — filed DOGFOOD-MESH-2.
- Working minimal round-trip (Python, `websocket-client`):

```python
import json, uuid, datetime, websocket
def now(): return datetime.datetime.now(datetime.timezone.utc).isoformat()
def peer(aid):
    ws = websocket.create_connection(f"ws://localhost:8769/mesh/connect/{aid}", timeout=20)
    ws.send(json.dumps({"type":"REGISTER","version":1,"message_id":uuid.uuid4().hex[:24],
        "timestamp":now(),"agent_id":aid,"lease_id":"","lease_ttl_ms":3600000,
        "capabilities":{"version":"0.1.0","topics":[],"max_concurrent_sessions":10}}))
    return ws
mid = uuid.uuid4().hex[:24]
alpha, beta = peer("alpha"), peer("beta")
alpha.send(json.dumps({"type":"REQUEST","version":1,"message_id":mid,"timestamp":now(),
    "source":{"agent_id":"alpha"},"target":{"agent_id":"beta"},
    "method":"GET","path":"/ping","body":{"q":1},"trace_id":uuid.uuid4().hex[:24],"timeout_ms":5000}))
req = json.loads(beta.recv())           # the REQUEST, relayed verbatim
beta.send(json.dumps({"type":"RESPONSE","version":1,"message_id":uuid.uuid4().hex[:24],
    "timestamp":now(),"request_id":req["message_id"],"source":{"agent_id":"beta"},
    "status_code":200,"body":json.dumps({"pong":True}),"trace_id":req["trace_id"]}))
print(json.loads(alpha.recv()))          # RESPONSE, body is a JSON-encoded STRING
```

### 3. Durable inbox + MCP bridge (crier-mcp remote mode)
- `deliver_message` → 201; `retrieve_inbox` → leased messages; bridge logs each
  env mistake at startup (missing auth token, missing CRIER_MESH_URL) — good.
- Ephemeral-key trap (documented in README, but bit me anyway): the bridge
  generates a fresh ed25519 key per run; the FIRST run registers that key for
  CRIER_AGENT_ID. A SECOND run with the same id and a new ephemeral key gets
  401 "signature verification failed" on every inbox read. Use a stable key:
  `openssl genpkey -algorithm ED25519 -out ~/.config/crier/<agent>.key` and
  `CRIER_AGENT_PRIVATE_KEY_FILE=...`. With a stable key the whole
  deliver→retrieve round-trip works against a signed (default) server.
- `get_messages` (bridge-managed lease+ack) works and returns [] when empty.

## Verdict
PROMISING-BUT-ROUGH. Everything a real integration needs WORKS — the friction
is all at the doc/wire boundary: frame shapes the docs don't show, an example
that omits a required header, and a doc example that contradicts the wire.
