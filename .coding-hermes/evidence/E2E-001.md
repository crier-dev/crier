## What the battery covers (24 gates, exit code = FAIL count)

posture (/health, /version, /status: memory backend + sig required + auth on) ·
security negatives (unauthenticated /agents 401, unauthenticated register 401,
bearer publish without X-Agent-ID 401 rate-limiter, signed inbox of
never-registered id 404 = existence-before-signature) · agent lifecycle
(register 201, duplicate 409, deliver 201, signed stats, signed retrieve w/
lease, signed ack lease+message_ids 204, empty retrieve) · relay (publish 202

`bat.*` fanout — bearer-authenticated WS, both subscribed before the publish) ·
ttl (`ttl_seconds:1` expires, retrieve-after-2s returns zero messages) ·
teardown (server killed, port freed asserted).

Server posture per run: env-isolated (`env -i`), memory backend,
CR_REQUIRE_AGENT_SIG=true, CR_GUARD_ENABLED=false, CR_RATE_LIMIT_PER_MINUTE=600,
CR_AUTH_TOKEN=<battery token>, scratch port pre-checked free with rotation,
holder-pid asserted equal to the started pid.
